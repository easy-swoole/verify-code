# Bundled captcha fonts

The bundled fonts are subsets of fonts from the official
[Google Fonts repository](https://github.com/google/fonts). Each subset contains
only `0-9`, `A-Z`, and `a-z` plus required font control glyphs.

Subsetting modifies the original font files. To avoid using Reserved Font Names
for modified versions, every subset has been renamed internally with the prefix
`EasySwoole Captcha` and the suffix `Subset`.
